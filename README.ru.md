## ✨ Ключевые возможности

### 🧠 Интеграция с различными LLM
Бесшовное подключение к вашим любимым ИИ-провайдерам. Поддержка:
- **Облачные провайдеры:** OpenAI, Anthropic, Google Gemini, Groq, DeepSeek, OpenRouter, Qwen.
- **Локальные LLM:** Полная интеграция с **Ollama** для приватной и автономной работы ИИ.
- **Кастомные модели:** Поддержка ввода ID сторонних моделей для максимальной гибкости.

### 🛠️ Возможности Агента
Больше, чем просто чат-бот. AI Assistant может взаимодействовать с вашей системой для решения реальных задач:
- **Режим Кодера:** Специализированная среда для разработки ПО, включающая:
    - Встроенный редактор кода.
    - Терминал для выполнения команд.
    - Проводник файлов для навигации по проекту.
- **Системные инструменты:** Способность анализировать экран, управлять файлами и выполнять системные задачи.
- **Управление знаниями:** Организация и передача контекста ИИ через выделенную базу знаний.
- **Неограниченный режим:** Опция отключения ограничений ответов ИИ для продвинутых пользователей.

### 🎙️ Голос и Аудио
Полностью интегрированный голосовой интерфейс для управления без рук:
- **Голосовой помощник в фоне:** Постоянно слушает пользовательские **слова активации** (например, «Ассистент»), чтобы мгновенно включить ИИ.
- **Интеграция с Windows SAPI:** Используйте любой установленный в системе голос для синтеза речи (TTS).
- **Интерактивный тест микрофона:** Визуализация уровня аудио в реальном времени (в стиле Discord) для проверки работы микрофона.
- **Настройка речи:** Регулировка скорости и громкости речи для индивидуального комфорта.

### 🖥️ Интеграция с Windows
Разработан специально для экосистемы Windows:
- **Глобальный хоткей:** Мгновенный вызов помощника с помощью настраиваемой комбинации клавиш (по умолчанию `Alt+Shift+G`).
- **Системный трей:** Работает незаметно в фоновом режиме с иконкой в трее для быстрого доступа.
- **Автозагрузка:** Возможность автоматического запуска вместе с Windows.
- **Нативная производительность:** Построен на Electron и React для плавного и отзывчивого интерфейса.

### 🎨 Современный UI/UX
- **Элегантный интерфейс:** Создан с использованием Tailwind CSS и Framer Motion для плавных анимаций.
- **Многоязычность:** Полная локализация (английский, русский) для пользователей по всему миру.
- **Поддержка Markdown:** Отрисовка богатого текста с подсветкой синтаксиса для кода.
- **Гибкие настройки:** Детальная конфигурация провайдеров, моделей и поведения системы.
- **Логи приложения:** Встроенный просмотр логов в реальном времени с фильтрацией по уровням (Info, Warn, Error) для отладки.

## 🚀 Быстрый старт

### Требования
- **Node.js** 18+ (рекомендуется v20 LTS)
- **npm** 9+
- **Windows 10/11**

### Установка
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/t1m0nch1k/AI-chat-asistant.git
   cd AI-chat-asistant
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите в режиме разработки:
   ```bash
   npm run dev
   ```

## ⚙️ Настройка

### Настройка ИИ-провайдеров
1. Откройте приложение и нажмите на иконку ⚙️ **Настройки**.
2. Перейдите на вкладку **Провайдер**.
3. Выберите вашего провайдера (например, OpenAI, Gemini, Ollama).
4. Введите ваш API ключ и сохраните настройки.

### Локальный ИИ с Ollama
1. Установите [Ollama](https://ollama.com).
2. Загрузите модель: `ollama pull llama3.1`.
3. В настройках приложения выберите **Ollama** в качестве провайдера.

## 🔨 Разработка и сборка

### Доступные скрипты
- `npm run dev`: Запуск приложения в режиме разработки с hot-reload.
- `npm run build`: Компиляция кода TypeScript и React.
- `npm run package`: Сборка финальных инсталляторов (NSIS и Portable).
- `npm run package:portable`: Сборка только портативной версии `.exe`.

### Архитектура сборки
Проект использует `electron-vite` для современного конвейера сборки:
- **Main Process:** Backend на Node.js для доступа к системе.
- **Preload Script:** Безопасный мост между Main и Renderer.
- **Renderer Process:** Frontend на React для пользовательского интерфейса.
